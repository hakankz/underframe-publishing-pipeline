01

About the application

UNDERFRAME Publishing Pipeline is a private internal software application operated by Hakan Korkmaz for managing and publishing content to the UNDERFRAME YouTube channel.

The application is used only by its owner. It is not offered as a public service and is not available for use by third parties. This website provides public information about the application and its privacy practices.

02

How it uses YouTube

UNDERFRAME Publishing Pipeline uses YouTube API Services to assist with repetitive publishing and channel-management tasks. Depending on the publishing workflow, the application may use the YouTube Data API to:

  • Upload videos to the authorized YouTube channel
  • Set and update video titles, descriptions, and other metadata
  • Upload or manage video thumbnails
  • Set video privacy and publishing information
  • Schedule video publication
  • Retrieve basic channel and video information required by the publishing workflow

All actions requiring authorization are performed only for the Google/YouTube account authorized by the operator.

03

Data and privacy

Information obtained through YouTube API Services is used only for operating the UNDERFRAME publishing workflow and managing the authorized YouTube channel.

The application does not sell YouTube user data or provide YouTube account data to advertisers.

Read the UNDERFRAME Publishing Pipeline Privacy Policy for details about data access, storage, deletion, and revoking authorization.

04

Terms of use

UNDERFRAME Publishing Pipeline uses YouTube API Services. By using the application, the operator agrees to be bound by the YouTube Terms of Service.

Use of the application is subject to its Privacy Policy. Information processed by Google is subject to the Google Privacy Policy.
