1. Introduction

This Privacy Policy describes how UNDERFRAME Publishing Pipeline (“the application”) accesses, uses, stores, and protects information obtained through Google and YouTube API Services.

UNDERFRAME Publishing Pipeline is a private internal application operated by Hakan Korkmaz. It is used to manage and publish content to the operator’s own YouTube channel and is not currently offered to third-party users.

This public website provides information about the application. It does not provide access to the private publishing tool or request authorization to a visitor’s Google account.

2. Use of YouTube API Services

The application uses YouTube API Services, including the YouTube Data API, to perform authorized channel-management and publishing functions.

These functions may include uploading videos, setting or updating video titles and descriptions, managing thumbnails, setting privacy and publishing information, scheduling publication, and retrieving channel or video information necessary for the publishing workflow.

3. Information the application may access

When the operator authorizes the application through Google OAuth, the application may access information necessary to perform the functions authorized by the operator. This may include:

  • YouTube channel identifiers and basic channel information
  • Video identifiers
  • Video titles, descriptions, thumbnails, and other metadata
  • Video privacy and publishing status
  • Information necessary to upload or manage videos
  • OAuth authorization tokens required to communicate securely with YouTube API Services

The application does not request or store the operator’s Google or YouTube password.

4. How information is used

Information obtained through YouTube API Services is used solely to operate the UNDERFRAME publishing workflow and manage the authorized YouTube channel.

The information is not used to build advertising profiles, track unrelated browsing activity, or perform surveillance of YouTube users. The application does not sell YouTube API data.

5. Sharing of information

YouTube API data accessed by the application is not sold, rented, or provided to advertisers.

The application is intended for the private use of its operator and does not provide authorized YouTube account information to unrelated third parties. Videos and associated publishing information are sent to YouTube when the operator authorizes publication or management actions.

Information may be disclosed where required by applicable law or where necessary to protect the security and integrity of the application.

6. Data storage and retention

The application stores only information reasonably necessary to operate the publishing workflow.

Authorization credentials and tokens may be stored securely for as long as they are required to maintain authorized access to the operator’s account.

YouTube API data that is temporarily cached or stored is deleted or refreshed when it is no longer required and in accordance with applicable YouTube API Services policies. Where those policies require API data to be refreshed or deleted within a specified period, the application follows those requirements.

7. Security

Reasonable technical and organizational safeguards are used to protect authorization credentials and information accessed through YouTube API Services from unauthorized access, disclosure, alteration, or misuse.

API credentials and OAuth authorization tokens are not intentionally made publicly available.

8. Cookies and tracking

The application does not operate a public user-facing service and does not use advertising cookies or behavioral tracking technologies for external users.

This information website does not include analytics scripts, advertising, embedded videos, or contact forms. Its hosting provider may process basic connection information, such as IP addresses and request details, to deliver and protect the website.

9. User control and revocation

Google account authorization granted to UNDERFRAME Publishing Pipeline can be revoked at any time through the Google Account third-party access settings. Select the application and remove its access.

Revoking access prevents the application from making future authorized requests using that authorization. Revocation is available in addition to the data-deletion procedure below.

10. Data deletion

Because the application is currently used only by its owner, deletion of locally stored authorization information or YouTube API data can be performed directly by the operator.

To request deletion of information associated with the application, contact mm.bt@hotmail.com. The operator will delete the relevant stored information as soon as possible and within seven calendar days of a deletion request.

After access is revoked through Google Account settings, associated stored API data will be deleted as soon as possible and no later than 30 calendar days after revocation. Deleting data held by the application does not itself delete videos or other information held by YouTube.

11. Google and YouTube policies

UNDERFRAME Publishing Pipeline uses YouTube API Services. By using the application, the operator agrees to be bound by the YouTube Terms of Service. The application’s terms of use are available on the overview page.

Information processed by Google is subject to the Google Privacy Policy.

12. Changes to this Privacy Policy

This Privacy Policy may be updated if the application’s functionality, data practices, or applicable API requirements change.

The latest version will be published on this page together with its effective date.
